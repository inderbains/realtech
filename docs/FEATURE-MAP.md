# Feature map

## CRM & marketing
- Leads, lead view/new lead, pipeline, tasks/follow-ups
- Lead scoring, auto follow-up/drip, bulk email, email templates
- Website lead forms, buyer alerts, home-worth leads
- Google/Meta lead integrations, webhook logs, round robin/source-based distribution
- SMS / WhatsApp integration points
- Imports and import history

## Agent & brokerage
- Agent profiles, invites, permissions, team/lead settings
- Multi-brokerage SaaS data model and branding
- Listings, listing images, public property pages
- Open-house events and client capture
- Goals and performance tracking
- Resources and community feed
- Internal messaging / notifications

## Transactions & back office
- Transaction creation/edit/view, multi-agent transactions, documents and notes
- Workflow states, admin review, audit logs and compliance
- Lawyer directory / letters
- Commissions, commission plans, statements, calculations and payments
- Agent receivables, brokerage payables, payroll/T4A
- Banking ledger, trust ledger, trust releases and monthly reconciliation
- Reports and cheque/statement output integration points

## SignVolt / e-sign
- Signature documents, files, signers, fields and field values
- Templates, template files/fields/roles
- Saved signatures/profiles
- Events, email logs, attachments, completion/certification data
- Legacy backup signature tables retained in schema

## SaaS/public
- Login/signup/password reset/email verification
- Demo requests
- Brokerage subscriptions/billing event tables
- Public buyer/seller guides and property lead capture
